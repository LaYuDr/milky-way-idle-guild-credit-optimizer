# 银河奶牛公会计算辅助插件

为《银河奶牛放置》（Milky Way Idle）的公会系统提供只读计算辅助，帮助规划公会信用点兑换、神龛升级与公会建筑建设顺序。

脚本不会自动购买、出售、兑换或升级；神龛指引只会在玩家主动选中规划物品后预填兑换数量，不会点击“兑换”。脚本不会上传账号数据，也不会读取登录凭据。

## 功能

- 展示八种公会信用点的前五项兑换方案、单点成本与目标成本。
- 支持以市场左一（最低出售价）或右一（最高收购价）作为参考；右一低于游戏当前可交易区间时自动忽略无效报价。
- 在游戏原生兑换窗口旁显示当前物品与最优物品的成本对比；原生窗口关闭后提示同步消失。
- 支持多项神龛升级规划，汇总材料、背包库存缺口、预计金币与公会代币成本。
- 神龛规划可一键把全部信用点缺口改按公会商店固定比例使用公会代币兑换，并合并显示代币总需求与库存缺口。
- 自动兑换代币预算支持滑块与数值输入同步调整；滑块实时显示百分比，并在 20%、40%、50%、60%、80%、100% 附近提供磁吸卡点。
- 可一键把生活或战斗神龛设为当前公会建筑等级对应的目标等级，也可清空全部计划；空计划刷新后保持为空，只会通过“添加神龛”或一键填充显式新增。
- 顶部设置可按生活与战斗分类逐项决定哪些神龛参与一键填充；取消勾选只跳过今后的批量填充，不删除已有计划，也不限制手工添加。
- 神龛规划提供可随时开关的高亮指引：依次标出待补信用点、最优兑换物品、兑换数量与最终需要升级的生活或战斗神龛；玩家主动选中规划物品后，右侧推荐浮层下方会显示规划批数，并一次性预填“你获得”数量。若库存不足，则按当前库存可完成的全部兑换批次填写；玩家仍可手工修改，插件不会点击“兑换”。
- 在材料规划与兑换排行中显示最优兑换物品、所需数量、背包库存；点击物品图标会调用游戏原生的“前往市场”功能并定位该物品。
- 计算公会代币兑换各色信用点的估算金币价值；该区域与八色兑换列表均可折叠。
- 可填写单件市场价上限（单位 M），使当前左一或右一参考价超过上限的物品不参与性价比比较。
- 记住目标信用点、价格参考、单件市场价上限、折叠状态、神龛计划、一键填充范围、最后打开的页面以及内部页签的自定义顺序，刷新网页或重新打开浏览器后继续使用。
- 为会长和管理员提供只读的公会建设工作台：覆盖 23 座普通建筑与 5 座神龛的 1 至 20 级费用，以紧凑的自适应方块网格连续添加、筛选和搜索建筑；完整建筑快照中未出现的建筑按未建造的 0 级处理，只有尚未取得完整快照时才要求手工确认。
- 设置中可隐藏“公会建设”页面；若隐藏时正处于该页，插件会安全切换到相邻可见页。已有建设计划和完整页签顺序会原样保留，重新显示时恢复原位置。
- 可设置手工公会点数预算和多座建筑的目标等级；施工计划按整座建筑拖动排序并持久化，也保留提前、延后按钮。逐级费用默认折叠，摘要会精确显示预算可完成的升级数、截止建筑和下一等级缺口。
- 当前建筑等级以“已读取数量 / 28”显示；取得完整快照后会把未建造建筑计为已知的 0 级。施工计划支持显式移除、清空后限时撤销，并在重绘后恢复到正在操作的建筑控件。
- 公会建设计划按站点与角色分别保存；可复制纯文本计划或在主动点击后导出 CSV，不会自动升级建筑。
- 自动适配游戏语言：中文游戏显示完整中文界面；英文或其他非中文游戏语言显示完整英文界面（包含侧栏页签、浮窗、按钮、提示与数字格式）。

## 数据来源与边界

- 市场价格以游戏公开的 `game_data/marketplace.json` 快照为基线；两个官方域名均不可用时，最后尝试 [q7.nainai.eu.org 备用快照](https://q7.nainai.eu.org/game_data/marketplace.json)。成功快照会保存在本地并在 15 分钟内复用，同时触发的读取会合并为一次请求。任一快照端点返回 `403` 时，对应域名暂停请求 10 分钟，并继续使用最近一次有效快照显示估算。玩家主动打开某个商品的原生市场页面后，插件会被动保存游戏已返回的该商品最新买卖价和可交易区间并优先用于估算。买价与卖价会分别更新，缓存可跨页面刷新与浏览器重启保留；与刚到达实时消息冲突的快照会延迟一次淘汰，异常缺项的快照也不会立即覆盖完整数据。插件自身不发送交易或订单簿请求。
- 兑换规则、神龛规则、当前公会等级与角色库存来自当前游戏页面已提供的数据。建筑完整快照中省略的建筑依照游戏语义视为未建造的 0 级；只有数据完整性尚未确认时，插件才会要求手工输入而不猜测结果。
- 公会建筑的逐级点数规则使用项目内带版本标记的静态表（`2026-08-04-v1`）；当前建筑等级仍只从游戏页面读取。插件没有可靠读取到公会剩余点数时，预算保持为空并要求管理员手工填写，不会猜测余额。
- 中文物品名称唯一优先来源是游戏官方 i18n 的 `itemNames` 目录；目录暂时不可读时使用上次本地缓存；仍未命中时显示游戏原始英文名。插件不维护静态中文物品表，也不自行拼接护符等名称。
- 插件只使用每个订单簿方向的最优报价，不使用完整市场深度；兑换排行与“卖出后回购”提示仅用于估算比较。卖出后回购按最新可用收购价、卖价及 2% 卖方税计算；买方手续费按 0 计算。
- 只有识别到游戏右侧侧栏后，插件才会插入“信用 / Credits”页签；中文与英文原生侧栏均支持。

工程结构、开发约定和发布策略分别见

开发加载器仅用于本地调试：启动开发服务后，在 Tampermonkey 中安装
`http://127.0.0.1:4173/milky-way-idle-guild-credit-dev-loader.user.js`。

响应式布局可用同一个测试台做宽度矩阵审计：访问
`http://127.0.0.1:4173/test-harness.html?layoutAudit=1&resetState=1&auditPlans=4&sidebarWidth=420`，
将 `sidebarWidth` 替换为测试契约列出的各档宽度。页面准备完成后会设置
`body[data-layout-audit-ready="true"]`，并把横向溢出、神龛行高、预算区、成本摘要和材料卡片的实测结果写入
`#layout-audit-output`，便于浏览器自动化逐档比较，不再只凭截图猜断点。

公会建设界面可用
`http://127.0.0.1:4173/test-harness.html?constructionAudit=1&resetState=1&sidebarWidth=420`
进行独立审计。测试台会生成包含预算截止线的九级施工队列，并将建筑方块数量、网格列数、方块宽高比、建筑组顺序、双栏状态、横向溢出和控件重叠结果写入同一个输出节点。

设置、神龛一键填充范围与建设页隐藏可用
`http://127.0.0.1:4173/test-harness.html?settingsAudit=1&resetState=1&sidebarWidth=420`
进行端到端审计。测试台会验证精神神龛（生活）可单独排除、精神神龛（战斗）仍可填充、已有排除计划不被删除、整类排除不会清空计划，以及隐藏当前建设页后的页面回退、键盘导航、可见页签拖动、重新开启建设页、完整顺序和建设计划保留。它同时输出设置区的 ARIA、焦点、横向溢出与控件重叠结果；审计失败也会在输出节点留下错误而不会只表现为等待超时。

每次正式发布会在 `releases/v主版本.次版本/` 下保留对应完整版本号的不可变构建产物；`dist/` 只存放当前安装入口与开发产物。当前安装入口始终是未带版本号的脚本文件。完整保存规则见 [历史版本说明](releases/README.md)，变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 一键发布

后续完成代码修改后，在项目目录只需运行：

```bash
npm run release
```

也可以从任意目录执行根目录下的 `发布当前版本.command`。脚本会自动递增补丁版本（若 `package.json` 已设置为更高版本则沿用）、补充默认变更记录、运行完整测试与构建、显式暂存发布白名单内的文件、提交并推送 `main`，最后核对 GitHub 远端提交及 Greasy Fork 的公开版本。

发布脚本不会使用 `git add .`。它只会新增本次版本的历史归档，既有历史版本不允许覆盖；截图、补丁、未完成预览和本机参考插件统一放入被忽略的 `.workbench/`，不会进入提交。若构建意外改写历史归档、暂存区不为空、分支或远端不正确，脚本会在提交前停止。

需要先查看将发布哪些文件而不产生任何修改时运行：

```bash
npm run release:dry-run
```

可选参数包括 `--version X.Y.Z`、`--message "提交说明"` 与 `--notes "变更记录"`。
