# 公会助手

为《银河奶牛放置》（Milky Way Idle）提供信用点兑换比较、神龛升级规划、公会建设预算和历史试炼记录。安装后刷新游戏，在右侧侧栏打开「公会助手」。支持中文与英文。

## 主要功能

- **信用点兑换比较**：比较材料成本、单点成本和预计总成本，结合市场参考价寻找兑换方案。
- **神龛升级规划**：汇总多项升级需求、库存和材料缺口。指引可定位游戏页面并预填数量，最终购买、兑换和升级由玩家点击确认。
- **公会建设预算**：按施工顺序核对建筑成本，结合预算和已保存的公会点数历史估算完成进度。未知数据和预测值会注明。
- **历史试炼记录**：玩家打开游戏试炼统计后保存已返回的数据，支持跨周查看、成员明细和 JSON 导入导出。试炼记录、计划和设置保存在本地，不上传至统计服务；未采集的旧记录不能自动找回。

市场参考价与预计成本不保证成交价格或数量。插件不会自动购买、出售、兑换或升级，不读取登录凭据，不上传游戏数据。安装与活跃统计会发送下述有限字段。

## 安装与活跃统计及隐私

公会助手的安装与活跃统计默认开启，可在游戏内「公会助手 → 设置 → 安装与活跃统计」关闭，不影响插件功能；升级保留已经保存的关闭选择。

- 开启时仅向柆雨的统计服务发送插件标识、版本和随机安装标识的 SHA-256 摘要，用于统计安装数与每日活跃安装数，不统计游戏内操作。
- 不使用硬件指纹，不发送账号、角色、聊天、资产、交易或 Cookie。安装标识仅保存在该脚本的 Tampermonkey 存储中；摘要用于识别同一安装。请求通过 HTTPS 发送。
- **关闭时仍会尝试发送一次仅含插件标识和版本的关闭事件**，不含安装标识或其摘要，失败不重试；之后不再上报，已有历史保留。关闭事件只统计操作次数。
